The real Anki engine,
native on iPhone.

Ankios wraps Anki's actual Rust backend in a fast SwiftUI app. Same scheduler, same sync, same cards as desktop Anki.

Download for iPhone Build from source

Nothing was reimplemented.

Most mobile flashcard apps rebuild Anki's logic and get it subtly wrong. Ankios cross-compiles the unmodified anki crate for iOS: FSRS scheduling, SQLite storage, card templates, and AnkiWeb sync behave exactly like they do everywhere else, because it is the same code.

SwiftUI interface Swift, iOS 26
Protobuf bridge the same messages desktop uses
Anki Rust backend FSRS, storage, sync

Small app. Full engine.

What it does today

FSRS scheduling

The modern spaced-repetition algorithm, straight from the Anki crate. Your intervals match desktop to the day, and undo works mid-session.

AnkiWeb sync

Sign in with your AnkiWeb account. Self-hosted sync servers work too.

APKG import

Open shared decks from the Files app, straight into your collection.

Images and audio

Media is served to cards through a native URL scheme handler, with tap-to-replay sound.

Daily reminder

One optional local notification, at the hour you pick. No account, no server.

Confetti

Finish a deck, get confetti. Streaks are hard, celebrate them.

Get it on your phone

1

Grab the app

Download Ankios.ipa from the latest GitHub release.

2

Sideload it

Open the file with AltStore or Sideloadly and sign in with your free Apple ID.

3

Trust and launch

On the phone: Settings, General, VPN & Device Management, then trust your profile.

Free Apple IDs re-sign apps every 7 days; AltStore automates the refresh. Requires iOS 26 or later.

Prefer to build it yourself?

The app compiles against an upstream Anki checkout. Full instructions live in the README.

git clone https://github.com/ankitects/anki.git
cd anki
git clone https://github.com/edouaz/ankios.git ios
# add "ios/rsbridge-ios" to the workspace members
ios/build-xcframework.sh
ios/gen-proto.sh
open ios/AnkiApp/AnkiApp.xcodeproj
